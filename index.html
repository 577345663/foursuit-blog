# Foursuit! Beta 0.1 — Development Notes **Date:** Early May 2026 **Status:** Beta 0.1 live / first public test build **Site:** playfoursuit.com **Feedback:** x.com/foursuit --- ## Overview Foursuit! began as a small standard-deck browser game concept: a simple card battle inspired by War, but with more agency, more structure, and a tactical scoring layer. The current beta includes two presentations of the same core game: * **Foursuit!** — Classic card-table version * **Loresuit!** — Fantasy flavor version Both versions use the same engine: hidden 3×3 card placement, reveal-based comparison, royal powers, score-difference rounds, and the Royal Parlay. --- ## Current Beta 0.1 Status Beta 0.1 includes: * Classic Foursuit! * Fantasy Loresuit! * three modes * three difficulties * Royal Parlay * Heir/Bloodline rule * tutorial * House Rules download * announcement modal * sound toggle * beta version badge * static website deployment Current goal: > Gather feedback, watch where players hesitate, and fix only what blocks understanding or playability. ## Next Likely Update * deeper Lore modal rewrite * more polished tutorial visuals * minor UI alignment fixes * more table-play notes * new dev diary / milestones No major mechanic changes are planned for Beta 0.1 unless testing reveals a real problem.
